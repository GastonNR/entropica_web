📖 Guía de Personalización del Sitio

Este archivo proporciona ejemplos de cómo personalizar el sitio de documentación.

1. Cambiar el Título y Logo

Edita el archivo index.html, busca la línea del header:

<h1 class="app-title">📚 Documentación Entrópica</h1>

Cambia por tu título preferido:

<h1 class="app-title">📊 Mi Sistema de Documentación</h1>

2. Modificar Colores y Estilos

Todos los colores están definidos al inicio de styles.css:

:root {
    --accent-primary: #3b82f6;  /* Azul - Cambiar a otro color */
    --accent-secondary: #10b981; /* Verde - Cambiar a otro color */
}
Ejemplos de colores:
  • #3b82f6 - Azul
  • #ef4444 - Rojo
  • #f59e0b - Ámbar
  • #8b5cf6 - Púrpura
  • #06b6d4 - Cian

3. Agregar Nueva Sección

Para agregar una nueva sección al menú:

Paso 1: Agrega el enlace en el sidebar (HTML):

<li>
    <a href="#mi-seccion" class="nav-link" data-section="mi-seccion">
        <span class="nav-icon">🆕</span>
        Mi Nueva Sección
    </a>
</li>

Paso 2: Agrega el contenido en el main-content (HTML):

<section id="mi-seccion" class="content-section">
    <h2>Mi Nueva Sección</h2>
    <p>Contenido de tu sección aquí...</p>
</section>
💡 Consejo: El data-section y el id deben coincidir para que el highlight funcione.

4. Personalizar Diagramas

Para agregar tu propio diagrama:

<iframe src="./public/diagramas/mi-diagrama.html" class="diagram-frame"></iframe>

Crea un archivo HTML en public/diagramas/mi-diagrama.html con tu contenido SVG o HTML.

5. Cambiar Tipografía

En styles.css, busca:

--font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", ...;

Para usar Google Fonts:

<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600&display=swap" rel="stylesheet">

Luego actualiza la variable CSS:

--font-family: 'Poppins', sans-serif;

6. Agregar Botones Personalizados

<button class="btn-primary">Mi Botón</button>

Los estilos ya están definidos en styles.css.

7. Modificar Tarjetas de Información

<div class="info-card">
    <h3>Título de la Tarjeta</h3>
    <p>Contenido de la tarjeta...</p>
</div>

8. Agregar Tabla de Datos

<table class="activity-table">
    <thead>
        <tr>
            <th>Encabezado 1</th>
            <th>Encabezado 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Dato</td>
            <td>Dato</td>
        </tr>
    </tbody>
</table>

9. Modificar Animaciones

En styles.css, busca @keyframes:

@keyframes fadeIn {
    from {
        opacity: 0;
        transform: translateY(10px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

10. Breakpoints Responsive

El sitio es responsive en estos tamaños:

  • @media (max-width: 768px) - Tablets
  • @media (max-width: 480px) - Móviles

Atajos de Teclado

  • Scroll Suave: Automático al hacer click en menú
  • Ctrl/Cmd + K: Preparado para búsqueda (futuro)
Nota Importante:

Siempre haz cambios en una copia local antes de hacer deploy. Prueba todas las funcionalidades antes de publicar en Netlify.

Estructura de URLs

El sitio usa anchors para navegar:

  • /index.html#introduccion → Sección Introducción
  • /index.html#metodologia → Sección Metodología
  • /login.html → Página de Login
