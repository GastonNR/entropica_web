⚡ Inicio Rápido

Abre el sitio localmente con un servidor HTTP simple:

$ cd "MDN - Entropic - version web" $ python -m http.server 8000 # Luego abre: http://localhost:8000
💡 Nota: Necesitas Python 3 instalado. Si prefieres Node.js, usa npx http-server

🌐 Deploy en Netlify

Paso 1: Preparar el repositorio

git init git add . git commit -m "Inicial: Documentación Entrópica" git remote add origin https://github.com/tu-usuario/tu-repo git push -u origin main

Paso 2: En Netlify.com

  • Crea una cuenta (usa GitHub para facilitar)
  • New site from Git → Conecta tu repositorio
  • Build settings automáticos (ya configurados)
  • Deploy!

Paso 3: Activar Autenticación

  • En Netlify Dashboard → Site Settings → Identity → Enable
  • Set Registration: "Invite only" (más seguro)
  • Invite users via email
✅ Listo! Tu sitio estará en https://tu-sitio.netlify.app o con tu dominio personalizado.

❓ Preguntas Frecuentes

¿Funciona sin Netlify?

Sí, es un sitio estático puro. Funciona en GitHub Pages, Vercel, cualquier servidor web. Solo la autenticación requiere Netlify Identity.

¿Cómo agrego más diagramas?

Crea archivos HTML o SVG en public/diagramas/ y embed con <iframe src="./public/diagramas/tu-diagrama.html" class="diagram-frame"></iframe>

¿Puedo cambiar la autenticación?

Sí. Usa Auth0, Firebase, o cualquier OAuth provider. Modifica auth.js para integrar tu proveedor.

¿Cuál es el costo?

Completamente gratis en Netlify (plan gratuito incluye hasta 300 build/mes). Netlify Identity también es gratis.

¿Puedo usarlo comercialmente?

Sí. Licencia MIT. Usa libremente en proyectos personales o comerciales.
